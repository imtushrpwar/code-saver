# CodeVault 🚀

CodeVault is a simple code snippet manager built with Node.js, Express, EJS, and MySQL.

## Features
- User Authentication
- Save Code Snippets
- Copy Code
- Delete Snippets
- Monaco Editor
- Dark Premium UI

## Tech Stack
- Node.js
- Express.js
- EJS
- MySQL
- Bootstrap 5

## Installation

```bash
npm install
npm start
